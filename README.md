# Lirrey Dvora

אתר תדמית בעמוד אחד — אוטומציות עסקיות לעסקי Wellness.

## הרצה מקומית

```bash
npm install
npm run dev
```

האתר ייפתח ב-`http://localhost:5173`.

## מספר WhatsApp

המספר וההודעה המוכנה נערכים בממשק הניהול, תחת "כללי".

## ממשק ניהול (Backoffice)

```bash
npm run admin
```

נפתח ב-`http://localhost:5173/admin/`. דרכו עורכים את כל הטקסטים באתר, את הפרויקטים (כולל הוספה, מחיקה, סידור ותמונות), את השאלון ואת פרטי הקשר.

- **שמירה** (או Ctrl+S) כותבת לקבצים במחשב, והתצוגה המקדימה מתעדכנת מיד.
- **פרסום לאתר** עושה commit ו-push רק לקובצי התוכן ולתמונות, ו-Vercel בונה את האתר מחדש.
- כריכה של פרויקט: מעלים תמונה אחת, והיא נשמרת אוטומטית בשלושת הגדלים (גדולה, 800px ו-JPG לשיתוף).
- הממשק רץ רק בשרת הפיתוח ועונה רק למחשב הזה. הוא לא נכנס לאתר שבאוויר.

## תוכן

התוכן נשמר כ-JSON ב-`src/content/data/` (site, articles, quiz, automations), ונערך דרך ממשק הניהול.
הקבצים `src/content/*.ts` רק טוענים אותו ומוסיפים טיפוסים ופונקציות עזר.

## תמונות

- `public/images/logo.png` — סמל על רקע שקוף
- `public/images/about.webp` — מומלץ להחליף בתמונה אמיתית של לירי
- שאר התמונות הן תמונות אווירה של Wellness / ריטריט / סטודיו
